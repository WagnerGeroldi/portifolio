Esta página foi desenvolvida para compreender o funcionamento do template Engine EJS
Como trabalhar com as Views e como "subir" esta aplicação em um serviço como a Heroku.
Não existe banco de dados nem validação nos inputs, o armazenamento dos dados é feito dentro do próprio sistema, em um arquivo JSON, que é consumido pela página inicial em um laço forEach.

Este foi o primeiro projeto que criei e mandei para a heroku, no final de 2021!
