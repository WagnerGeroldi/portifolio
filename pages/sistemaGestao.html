Minha atuação na empresa é de coordenador, então desenvilvi este sistema para poder gerir minha atuação.
Alimento ele com planilhas recebidas semanalmente através da supervisão, onde tenho controle de todas as unidades, alunos ativos, desistentes entre outros. Este sistema serve principalmente para gerar relátórios, onde recebo uma listagem com milhares de alunos e o sistema separa eles de acordo com as necessidades do negócio.
Este sistema não está implementado na web, apenas em localhost.

Informações

Front-End

Desenvolvido em REACT com TypeScript, e utilizado algumas bibliotecas para auxiliar no desenvolvimento.

  • Axios
  • PDF-MAKE
  • Yup
  • Material UI

Back-End

Desenvolvido em NODEJS com TypeScript, e utilizado algumas bibliotecas para auxiliar no desenvolvimento.

  • Sequelize
  • NodeMailer
  • Express
  • Bcrypt

Banco de Dados

  • MYSQL
