API REST - EJS - MONGODB

Acessar API Voltar ao início

Esta API foi desenvolvida com intuito de estudar o padrão REST, separando o back end do frontend, aliando o banco de dados MongoDB para guardar as informações, o BACKEND foi upado no serviço da heroku, o banco de dados no cloud do proprio mongoDB e o Front-End está no GitHub Pages.
O projeto foi desenvolvido seguindo regras da arquitetura MVC. Neste momento de estudo ainda não conhecia TypeScript, então foi desenvolvido em JS puro.

Informações

Front-End

  • EJS - Template Engine
  • HTML 5
  • CSS 3

Back-End

Desenvolvido em NODEJS, e utilizado algumas bibliotecas para auxiliar no desenvolvimento.

  • Mongoose
  • CORS
  • Express

Banco de Dados

  • MongoDB
